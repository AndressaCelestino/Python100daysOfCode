A beginner Python practice repository organized by class folders, with small command-line programs that build confidence in input handling, numeric conversion, arithmetic and formatted output.

View repository

Overview

The repository follows early 100-days-style Python lessons. Each script is intentionally short and interactive, asking for values in the terminal and printing a calculated result or generated phrase.

Features

Band name generator

Combines city and pet inputs into a simple generated band name.

Two-digit arithmetic

Reads a two-digit number, indexes each character and sums the converted digits.

BMI calculator

Accepts height and weight, converts input types and prints the integer BMI result.

Life-in-weeks estimate

Uses an entered age to calculate remaining weeks up to age 90.

Tip calculator

Splits a bill across people after applying a selected tip percentage and formats the output to two decimals.

Lesson folders

Groups exercises by lesson number so new practice files can be added without disturbing earlier work.

Tech Stack

  • Python 3
  • Command-line input
  • String indexing
  • Numeric casting
  • Formatted strings

How It Works

Run an individual script with Python from its lesson folder, answer the terminal prompts, and read the printed result. The exercises are standalone, so each file can be studied independently while practicing one small concept at a time.
